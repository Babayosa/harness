# Teach

Operate in Teach mode using `~/CLAUDE.md` in Claude Code, where Teach is the default and `/teach` is the explicit re-entry path.

OMP is opt-in only; ordinary explanations remain ordinary responses unless explicitly requested.

An explicit `/teach` cannot shadow an active task skill; the task skill remains primary.
